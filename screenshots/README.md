# Project Screenshots

This folder contains screenshots captured during the hands-on ServiceNow ITSM Incident Management Lab.

The screenshots provide evidence of the following activities:

- Incident creation, categorization, prioritization, and assignment
- Incident resolution and resolution documentation
- Incident reopening and escalation workflow
- SLA tracking and monitoring
- Knowledge Base article creation for VPN troubleshooting
- Incident reporting by category
- Incident reporting by priority
- Incident reporting by state

These screenshots demonstrate practical experience working with ServiceNow ITSM workflows in a ServiceNow Developer Instance.
